# 城市覆盖与停止规则

继续按区县、客户角色、目标行业、规范关键词族和来源类型覆盖。行业维度保留，但具体值来自本次行业配置。行政区须由真实目标城市确定，不能用一项占位区域声称全城覆盖。

初始化从配置注册全部词条，检查ID、内容、计数与顺序；没有固定词数。覆盖任务采用紧凑组合，不强制完整笛卡尔积。城市搜索空间与配置的角色、行业、来源和词族保持一致。

覆盖完成由实际查询记录证明。查询须关联任务、符合任务维度并有有效终止与访问记录；任务COMPLETED标签本身不算证据。来源受限、无实际访问或策略提前停止不得计入正常完成。

发现增量按全局入池企业计数。按绑定策略检查独立零新增SYSTEM_SEARCH轮次、有效查询数量、扩展审计、阻断缺口和未处置记录。standard/light至少3轮且每轮8条；strict至少4轮且每轮12条。返回词经测试和批准后才回流覆盖。累计FINAL数量不作为停止条件。

正式停止需要覆盖与收敛同时满足，并无阻断工作。冻结纳入城市状态、空间、配置、词库、扩展链、权限、策略、执行脚本、批次、查询及已登记证据和Worker输入。完整性检查拒绝空清单、重复文件、遗漏输入及文件哈希变化。全量重算核对增量结果，原始文件摘要变化则拒绝通过。

覆盖表按正式snapshot生成，不按当前批次缓存生成，也不只统计FINAL。企业名单、证据包与覆盖表对应同一snapshot_id。强制冻结仅用于诊断，不能让未完成任务正式交付。
