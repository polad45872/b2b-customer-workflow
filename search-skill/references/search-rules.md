# B2B 企业发现规则

目标由我方产品服务、企业角色和业务场景共同定义，关键词来自绑定词库。保留直接产品服务词、业务场景词、潜在需求线索词及配置中的其他词族；不内置任何行业技术清单。

从企业官网、政府园区名单、项目招投标、展会协会、招聘及相关公开资料搜索。按任务配置覆盖来源。招聘或专利可提示相关业务，不能自动证明企业规模、预算或采购关系。

实际访问企业业务和项目页面。发现来源不等于官网。每家线索提供公司名、发现查询、query_id、source_url、matched_keywords、preliminary_role、discovery_reason和lead_summary，并保留原始返回。主控解析法定主体，发现Worker不分配正式企业ID或核准FINAL。

五类搜索用途：产品服务供应、方案合作、终端业务应用、招聘线索、采购项目线索。按本次目标关系选择用途；查询命中供应商时先判断它是否属于目标角色，不把产品供方自动当作买方。

每个查询记录分配文本、实际访问URL、检查结果数、候选与重复数，以及BUDGET_EXHAUSTED、RESULTS_EXHAUSTED、SOURCE_BLOCKED、STRATEGY_STOP之一。来源受限保留日志，但不计入有效完成；定向企业核验不冒充基础词覆盖或独立发现轮次。

候选追溯的provenance将原始记录、查询、任务、企业与来源成组关联，并保存result_sha256；兼容数组由这些记录派生。禁止手填不相干查询来补齐来源数组。
